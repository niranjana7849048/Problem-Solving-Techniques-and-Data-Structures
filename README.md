# Day 1 – Problem Solving Techniques and Data Structures – I

## Overview
This day focuses on implementing searching, sorting, duplicate detection, Stack, Queue, Greedy algorithms, and Dynamic Programming using Python.

## Sets Completed

### Set 1 – Retail Order Desk
- Linear Search and Binary Search
- Bubble Sort and efficient sorting comparison
- Duplicate order detection
- Stack-based undo and Queue-based dispatch
- Greedy change-making and Dynamic Programming

### Set 2 – Retail Banking Transaction Review
- Transaction ID searching
- Insertion Sort and Merge Sort
- Duplicate transaction detection
- Queue-based review backlog and Stack-based adjustment reversal
- Divide and Conquer for minimum and maximum values

### Set 3 – Hospital Appointment Desk
- Patient searching using Linear Search and Binary Search
- Selection Sort and Quick Sort for appointments
- Double-booking detection using a Set
- Custom Stack and Queue implementation
- Dynamic Programming and Greedy comparison for appointment scheduling

## Technologies Used
- Python 3
- CSV files
- Data Structures and Algorithms

## Deliverables
- Python source code for all three sets
- CSV test datasets
- Console execution outputs
- Complexity analysis for each set

## Execution
Run each Python file from its respective set folder:

```bash
python retail_order_desk.py
python banking_transaction_review.py
python hospital_appointment_desk.py
```

## Outcome
Implemented and tested fundamental problem-solving techniques and data structures through retail, banking, and hospital management scenarios. Compared algorithm performance using execution time, comparisons, and swap counts.
